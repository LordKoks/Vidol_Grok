# TestBot Bot

## Описание
Это Telegram-бот, созданный с помощью Telegram Bot Builder.

## Команды
- `Start`: Описание команды.
  *Пример:* `Нажмите старт`
- `menu`: Описание команды.
  *Пример:* `нажмите меню`

## Установка
1. Установите зависимости: `pip install aiogram`
2. Запустите бота: `python bot.py`
